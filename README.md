# 싱싱냉장고 – 식재료 유통기한 관리 웹앱  
*(자취생·주부를 위한 가볍고 따뜻한 프리시전 그린 테마)*  

---  

## 📖 개요  

**싱싱냉장고**는 남은 식재료의 유통기한을 한눈에 확인하고, 수량·구매·소비를 기록할 수 있는 **정적 웹 애플리케이션**입니다.  

- **GitHub Pages**에 배포하면 별도의 서버 없이 언제 어디서든 URL 하나로 이용 가능  
- 데이터를 **`localStorage`**에 저장해 브라우저 종료·새로고침 후에도 유지  
- **CSV 파일**을 직접 **불러오기/내보내기**해 백업·복구가 쉽습니다  
- 임박·만료 식재료를 색상·애니메이션으로 강조 (파스텔 그린 + 경고 색)  


---  

## 🚀 시작하기  

### 1️⃣ 레포지토리 복제 (GitHub Pages 사용 시)  

```bash
# 레포지토리를 클론 (본인이 만든 레포지토리 URL)
git clone https://github.com/<YOUR_USERNAME>/sing-sing-refrigerator.git
cd sing-sing-refrigerator
```

### 2️⃣ GitHub Pages 활성화  

1. GitHub 웹 UI에서 **Settings → Pages** 로 이동  
2. **Source** 를 `main` 브랜치, **Folder** 를 `/ (root)` 로 선택 → **Save**  
3. 아래 초록 배너에 표시되는 URL을 복사  

```
https://<YOUR_USERNAME>.github.io/sing-sing-refrigerator/
```  

> **Tip** : 처음 배포 후 몇 초 정도 기다리면 바로 접근 가능  

### 3️⃣ 로컬에서 미리 보기 (옵션)  

```bash
# npm 이 필요 없으며, 정적 서버만 실행하면 됩니다
npx serve -s .
# 브라우저에서 http://localhost:8080 를 열어 확인
```

## 📚 사용법  

### 화면 구성  

| 구역 | 설명 |
|------|------|
| **헤더** | 로고·앱 이름·부제 → “자취생과 주부들을 위한 식자재 유통기한 도우미” |
| **기준 일자** | 현재 날짜 표시 (자동 업데이트) |
| **CSV 불러오기 / 내보내기** | 좌측 메타 영역에 위치 – 클릭 시 파일 선택 또는 다운로드 |
| **좌측 리스트** | 식재료 카드 (수량·이름·유통기한·D‑day) |
| **탭** | **전체 품목** / **임박·경과** (3일 이내·만료) |
| **검색** | 이름으로 실시간 필터링 |
| **우측 폼** | 새 식재료 추가·기존 식재료 수정 |
| **요약 카드** | 총 품목·임박·만료 개수 (색상·펄스 애니메이션) |

### 기본 흐름  

1. **앱 실행** → 기본 샘플 5품목이 보입니다.  
2. **새 식재료 등록**  
   - 이름, 수량, 유통기한 입력 → **등록하기** 클릭  
   - 카드와 요약이 즉시 업데이트  
3. **수정**  
   - 카드右의 ✏️ 버튼 클릭 → 폼에 값이 채워짐  
   - 변경 후 **수정 완료** 클릭 → 자동 저장·리렌더링  
4. **삭제**  
   - 카드右의 🗑️ 버튼 클릭 → 확인 창 → 삭제 후 요약 업데이트  
5. **검색·필터**  
   - 검색창에 키워드 입력 → 실시간 필터링  
   - **임박·경과** 탭 클릭 → 3일 이내·만료 식재료만 표시  
6. **CSV 내보내기**  
   - **CSV 내보내기** 버튼 클릭 → `ingredients.csv` 다운로드  
   - UTF‑8 BOM 포함, 엑셀·메모장에서 한글이 깨지지 않음  
7. **CSV 불러오기**  
   - **CSV 불러오기** 버튼 클릭 → 파일 선택 → 현재 데이터가 교체·갱신  

> **주의** : CSV를 불러오면 기존 `localStorage` 데이터가 **덮어쓰기**됩니다. 필요하면 미리 백업해 두세요.

## 🗒️ FAQ  

| 질문 | 답변 |
|------|------|
| **데이터가 사라졌어요.** | 브라우저 `localStorage`를 지우면 초기화됩니다. 백업용 CSV를 **내보내기**해 두세요. |
| **CSV 파일이 한글이 깨져요.** | 자동으로 **UTF‑8 BOM**을 포함해 저장합니다. 엑셀에서 “UTF‑8” 옵션을 선택해 열면 정상입니다. |
| **모바일에서도 사용할 수 있나요?** | 반응형 레이아웃을 적용했으니 스마트폰·태블릿에서도 정상 동작합니다. |
| **다른 사람과 데이터 공유하고 싶어요.** | CSV 파일을 **내보내기**하고, 그 파일을 공유하면 동일한 데이터를 가져올 수 있습니다. |
